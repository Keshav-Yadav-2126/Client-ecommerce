🛒 MERN E-Commerce Platform

A full-stack e-commerce application built with the MERN stack, featuring a modern shopping experience and an admin dashboard for managing products, users, orders, inventory, and sales.

🚀 Features

👤 User

JWT-based authentication with role-based access

Product search, filtering, sorting, and pagination

Product details, reviews & ratings

Shopping cart with guest and logged-in user support

Saved delivery addresses

Online payment integration

Order placement and tracking

🛠️ Admin

Product CRUD and Cloudinary image uploads

User and order management

Inventory and low-stock alerts

Sales dashboard and analytics

Coupon management

CSV export

🧰 Tech Stack

Frontend: React.js, Vite, JavaScript, Tailwind CSS, Shadcn UI, Zustand, React Hook Form, Zod, Axios

Backend: Node.js, Express.js, MongoDB, Mongoose, JWT

Services: Cloudinary, Online Payment Gateway

🔐 Authentication

JWT-based authentication with protected routes and role-based authorization for users and administrators.

☁️ Cloud Image Upload

Product images are uploaded using Multer and stored securely on Cloudinary.

⚙️ Installation

git clone YOUR_GITHUB_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
npm install
npm run dev

Create the required .env variables for MongoDB, JWT, Cloudinary, and payment services. Never commit API keys or secrets to GitHub.
